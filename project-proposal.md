## Project Proposal

**Chosen Track:** 

**Project:** Password Manager  
**Goal:** Implement user registration, adding passwords, and viewing saved passwords.  
**Stretch Goals:** Implement login, search passwords, and generate random passwords.


### Description

This program will allow users to store and manage their passwords in one secure place.  
Users will register with a username and a master password, which will be hashed before saving to keep it secure.  
After registering, users can add entries for different websites and accounts (site, username, password) and view their stored passwords later on.  
Data will be stored in local JSON files, and in future ships, I plan to add more features like password search and a random password generator.

### Planned Features
- Register a user with a master password (hashed for security)  
- Add and save passwords for different sites  
- Retrieve and list all saved passwords  


### Stretch Goals

- Implement login verification before showing passwords  
- Add search functionality for passwords by site name  
- Automatically generate strong random passwords
